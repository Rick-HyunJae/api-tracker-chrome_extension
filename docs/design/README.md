# design/

프로젝트의 디자인 패턴과 시스템을 정의하는 디렉토리.

## 개요

이 디렉토리는 특정 웹서비스의 디자인 언어(색상, 타이포그래피, 레이아웃, 컴포넌트 등)를 분석·문서화한 파일을 보관한다. 문서화 방식은 [getdesign.md](https://getdesign.md/) 의 접근법을 따른다.

분석된 디자인 문서는 UI 구현 시 참조 기준이 된다.

## 파일 추가 방법

특정 웹서비스의 디자인을 추출하려면 `extract-web-design` 스킬을 사용한다.

```
/extract-web-design <URL>
```

**유의 사항:** 대상 URL은 로그인·인증 없이 접근 가능해야 한다.

## 문서 구조

각 디자인 문서는 아래 섹션 순서로 작성한다. [`design.md`](./design.md) 를 작성 패턴의 기준으로 삼는다.

| 섹션                    | 내용                                                                                      |
| ----------------------- | ----------------------------------------------------------------------------------------- |
| **Overview**            | 디자인 시스템 전반 요약 — 캔버스, 주요 색상, 타입, 형태 언어의 핵심 특성                  |
| **Colors**              | Brand & Accent / Surface / Hairlines & Borders / Text / Semantic / Scrim 분류로 토큰 정의 |
| **Typography**          | 폰트 패밀리, 계층 테이블(토큰·크기·굵기·행간·자간·용도), 원칙                             |
| **Layout**              | 간격 시스템(베이스 단위·토큰), 그리드·컨테이너, 여백 철학                                 |
| **Elevation**           | 그림자 티어 정의 및 적용 대상                                                             |
| **Components**          | 버튼·검색·네비게이션·카드·폼·푸터 등 주요 컴포넌트 스펙                                   |
| **Responsive Behavior** | 브레이크포인트 테이블, 터치 타겟 크기, 축소 전략                                          |
| **Known Gaps**          | 추출되지 않은 상태·패턴 목록 (투명성 확보 목적)                                           |

### 토큰 표기 규칙

문서 내 디자인 토큰은 `{category.token-name}` 형식으로 참조한다.

```
{colors.primary}        → #ff385c
{typography.body-md}    → 16px / 400 / 1.5
{spacing.section}       → 64px
{rounded.full}          → 9999px
{component.search-orb}  → 컴포넌트 참조
```
